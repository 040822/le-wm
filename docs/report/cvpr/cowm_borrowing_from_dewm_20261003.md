# DeWM 与 Sub-JEPA 对 CoWM 的可借鉴设计：展开分析

日期：2026-10-03。本文展开前次审查中“哪些部分值得 CoWM 借鉴”，提出设计和实验对照；本轮没有修改 CoWM 模型或训练目标。DeWM 方法依据本地 `docs/paper/AAAI2027_Flow_JEPA.pdf`，不是同名公开 Flow-JEPA。

## 1. 先明确值得解决的问题

CoWM 当前 R4-AB 用同一视觉表示和 DiT 完成两件事：A 从高斯噪声生成目标条件动作，B 在一次调用中预测这些动作前缀的未来 latent。B 的终点距离既决定 P3 选哪个候选，也通过对动作的梯度决定 PO/GF 往哪里修正。

因此，表示改进是否有价值，要看三个层面：

1. 目标距离是否能区分真实执行效果不同的候选，而不只是区分图像外观。
2. 对动作的梯度是否指向可执行的改善方向，而不只是降低模型自己的距离。
3. 这些收益是否抵得过额外编码、预测及反向传播的决策成本。

DeWM 的空间分量提供一种可能更适合局部位置、几何变化及接触事件的距离。它并没有直接证明共享参数或 A→B 梯度耦合更有效，也没有解决生成动作对应反事实未来缺少监督的问题。当前 DeWM 工作树与论文方法有偏离，所以借鉴应依据清楚的设计和受控实验，不能照搬默认配置来解释论文成绩。

## 2. 两种 flow 并不是同一任务

| 分支 | 路径 | 条件 | 核心作用 |
|---|---|---|---|
| DeWM | `z_t → z_{t+1}` 的状态桥 | 当前状态、动作、积分时间 | 学习动作导致的单步 latent 变化，再递归 rollout |
| CoWM A | `ε → a_{0:H-1}` 的动作生成流 | 当前/目标 latent、积分时间 | 同时生成整个动作 chunk |
| CoWM B | 没有生成流；直接预测 future queries | 当前 latent、动作前缀、训练条件 s | 一次调用并行提供未来表示和可微评分 |

DeWM 的 flow 起点是当前状态，当前实现没有从高斯噪声生成随机未来。CoWM B 里的 s 表示动作估计的训练条件，不是 DeWM 的 latent 积分时间。两者可以同时存在，但不能复用一个字段就认为语义相同。

当前 CoWM R4-AB 不使用探索版本中的 D/E 训练目标。额外的目标条件 latent-path flow 也不等同于 DeWM 的 action-conditioned 单步状态桥。

## 3. 第一优先级：紧凑的局部空间表示

### 3.1 为什么可能有用

当前 `FastLeWAM.encode_pixels` 只取 ViT 的 CLS 再投影。CLS 本来就能吸收空间信息，但一个全局汇总向量没有显式保留哪块区域发生了变化。某个候选可能在全局表征上更接近目标，却在物体位姿或接触位置上更差；当局部变化在整体距离中权重较低时，B 的终点距离可能给出错误排序。

DeWM 从同一个 ViT 提取 patch tokens，恢复二维网格，做固定平均池化，再对每个位置使用共享的小投影头。局部位置被保留在固定的展平索引中。这种结构可能帮助区分物体位置、朝向、相对距离或局部位移，对 PushT、Cube 等任务值得验证。

这是关于结构和数据的假设，不是已经得到的 CoWM 实验结论。ViT patch 已经经过全局 attention；CLS 和 patch 分量也并非严格独立。把它们命名为 task-state / spatial-detail，不会自动赋予这些语义。

### 3.2 如何迁移到 CoWM

同一个 encoder 返回 CLS `h_cls` 和 patch 网格 `H_patch`，构造：

\[
z^G=g(h_{cls}),\quad
z^L=\operatorname{vec}\bigl(l(\operatorname{AvgPool}_{4\times4}(H_{patch}))\bigr),
\quad z=[z^G;z^L].
\]

首个候选方案保持总 latent 192 维：全局 128 维、16 个空间位置各 4 维，局部共 64 维。它保留现有 A/B 接口的维数及 transformer token 数，也保留 B 的 causal-prefix mask。这个划分是实验起点，不能称为 DeWM 的论文设置；后者优选 64+64。

A 接收新的当前/目标表示，B 仍只接收当前表示和动作。不要把 goal 的局部表示加进 B，也不要将未来观测作为 query 的输入。A/B 的参数共享、估计动作输入、梯度是否 detach、动作混合课程等，先保持现有协议，以免一次改变多个方法因素。

在实现上应新增一个实验模型/表示实现，集中修改 `encode_pixels` 的 CLS+patch 提取和投影。不能直接用 Hydra 替换 projector：当前调用只传 CLS，DeWM projector 接收 CLS+patch 且返回多个 tensor。紧凑向量可以继续供现有 A/B 消费，无需增加 16 个空间 attention tokens。

### 3.3 代价和风险

- 同一 ViT 已经产生 patch tokens，因此不需要第二次 backbone 编码；但局部投影确实有额外计算。若每个位置都用 2048 hidden 的 MLP，16 个位置的投影成本不能忽略，可先比较小 MLP 或线性头。
- 保持总 latent 维数不等于保持参数量/FLOPs完全相同。报告 encoder、projector、DiT 各部分参数和时间。
- 每个位置只有 4 维可能过度压缩；如果失败，要区分压缩不足与空间信息无用。先固定一个小规模设计，再根据开发数据决定是否有必要调整划分。
- 固定网格保留的是绝对图像布局，可能对镜头改变、物体跨池化格子、遮挡更敏感；它不是 object-centric 表示。
- 新 projector 的表示坐标发生变化，需要重新训练。不能将旧 CoWM 权重换一个 projector 就视为同一个模型。

### 3.4 必要对照

| 版本 | 表示 | 要回答的问题 |
|---|---|---|
| R0 | 当前 CLS→192 | 现有参考 |
| R1 | CLS 经两个头输出 128+64 | 两个头/监督拆分本身是否有用 |
| R2 | CLS→128，所有 patch 全局平均后→64 | patch 内容是否有用，不保留网格索引 |
| R3 | CLS→128，4×4 patch 网格→16×4 | 固定空间组织在 R2 之外是否有用 |

四个版本首先使用相同的整向量 B loss 和相同正则策略，尽量隔离表示来源。R1/R2/R3 的投影结构并不必然参数完全相同，仍需报告实际容量和成本；不能只凭总维数相同声称参数匹配。

第一批优先看 PushT/Cube 的候选排序与真实短段执行；TwoRoom 可能接近成功率天花板，可作为全局导航是否受损的检查；Reacher 用来检查连续控制是否退化。任务范围应预先指定，不能看完结果后只保留收益任务。

## 4. 第二优先级：分量化预测损失和规划评分

### 4.1 先拆评分，避免与表示训练混淆

在一个已经训练好的 G/L 表示模型上，先固定模型参数，只比较：

\[
J(a)=J_G(a)+\eta J_L(a).
\]

η=0 检查全局分量的独立作用；中间值检查组合；较大值检查局部分量对交互任务的帮助。η 应在开发样本上选定，随后在正式样本上冻结。正式评测中不能逐任务按成绩挑 η；若设计任务专属 η，应提前定义并完整报告。

如果把表示来源、B 的训练权重和 η 同时改变，就无法知道成绩来自哪一个因素。

### 4.2 必须明确距离的尺度

DeWM 当前评分用分量的误差平方和；CoWM 当前 B 评分用整向量 MSE。若全局/局部维数为 `d_G,d_L`：

\[
J_{sum}=d_G\operatorname{MSE}_G+\eta_{sum}d_L\operatorname{MSE}_L.
\]

除以不影响 argmin 的 `d_G` 后，与分量 MSE 写法等价的权重是：

\[
\eta_{MSE}=\eta_{sum}\frac{d_L}{d_G}.
\]

所以 DeWM 的 192+128 维、η_sum=0.25，转换成 `MSE_G+η_MSE MSE_L` 是 η_MSE=1/6，不是0.25。即使维数一样，表示方差和误差尺度不同，权重的实际作用仍会变化。

建议第一版把现有整向量 MSE 写成精确等价的分量公式：`(d_G/D) MSE_G + (d_L/D) MSE_L`，确认不改变原有排序；再明确改变局部系数。保存原始分量距离及权重，便于审查。不要在部署时用当前候选池统计临时重标定距离，这会让 cost 依赖池子及分片方式。

### 4.3 对 PO/GF 的作用更值得检查

若采用分量 MSE，动作梯度为：

\[
\nabla_a J
=\frac{2}{d_G}\left(\frac{\partial B_G}{\partial a}\right)^T(B_G-z_g^G)
+\eta\frac{2}{d_L}\left(\frac{\partial B_L}{\partial a}\right)^T(B_L-z_g^L).
\]

局部表示可能为接触位置或物体位移提供更有用的动作修正方向。但局部 Jacobian 也可能更不稳定，或者两类梯度彼此冲突。CoWM 当前 RMS 归一化控制总更新尺度，并不能保证梯度方向正确；局部项主导方向后，总梯度归一化不会消除这种主导。

建议记录 `||∇J_G||`、`||∇J_L||`、两者余弦、动作实际偏移和物理边界投影情况，检查 η 如何改变方向。对照保留现有 PO2、步长及 RMS trust region；首先改变评分权重，避免顺便调优化器。

PO 的验收必须包含实际执行后的改善。若模型 cost 降得更多而执行效果变差，应视为评分器利用了自身误差，不能称为更好的 refinement。

### 4.4 然后才改变 B 的训练监督

可将 B 的 latent loss 写成 `w_G L_B^G + w_L L_B^L`。先选择与当前整向量 MSE 等价的权重，再测试强调局部预测。保留同样的 recorded/estimated action 混合及 loss noise weighting，分别记录未加权分量损失和实际目标贡献。

不要直接套 DeWM 的“全局过程、局部结果”四项系数：CoWM B 当前只有未来表示预测，没有速度桥分支，二者并不是同一 loss 参数化。

## 5. 第三优先级：表示正则化

### 5.1 独立 SIGReg 与 Sub-JEPA 是不同设计

| 正则化 | 作用对象 | 对 CoWM 的主要假设 |
|---|---|---|
| 当前整向量 SIGReg | `[G;L]` 的随机一维投影 | 一套统计约束足以稳定整体表示 |
| 分量独立 SIGReg | 分别对 G 和 L 施加约束 | 两种表示可以保持不同的联合统计结构 |
| Sub-JEPA | 原 latent 经多个冻结随机低维投影后的表示 | 放松全空间约束有助于保持任务相关几何 |

独立 SIGReg 不保证 G/L 在概率上独立，也不保证其语义解耦。Sub-JEPA 的随机子空间也不是固定的语义分区；其投影通常会混合原 latent 的许多坐标。

### 5.2 对 CoWM 最小的实验路径

先在当前 CLS-only 的 CoWM 上，只把 SIGReg 换成官方 `MultiSubspaceSIGReg`，保持 A/B 的模型、目标梯度、动作课程和推理不变。这样可以单独判断更弱的整体统计约束是否有价值。

可以把官方的 D=192、PushT K=16、其他任务 K=32 当成明确来源的实验起点，不能认为这些值在 CoWM 的联合训练中已经最优。正则器输入是 `[B,T,D]`；现有普通 SIGReg 使用 `[T,B,D]`，不能照搬转置。

再在已经确定的 G/L 表示上比较整向量和独立 SIGReg。需要明确 `λ(R_G+R_L)` 与 `λ/2(R_G+R_L)` 的强度不同；不应把两路求和后直接与一路使用同一个 λ 就称为完全匹配的对照。

最后才考虑每个语义块内部再用 Sub-JEPA。过多低维子空间可能使估计和训练不稳定，并增加显存；不建议一开始就同时引入空间表示、分量 loss 和分量 Sub-JEPA。

### 5.3 监测什么

记录两类表示的方差/协方差谱、有效秩、局部位置间相似度、prediction error 和实际决策效果。有效秩降低本身既可能表示更紧凑，也可能表示坍塌，需要与信息探针及规划结果一起解释。

SIGReg 的统计依赖 batch 内样本。为了省显存，沿 K 分片可以设计等价计算；把 B 分片各自算完再平均则改变了统计目标，不应当作透明的内存优化。

## 6. 低优先级：过程/结果监督与 flow 动力学

### 6.1 可以借鉴的是对完整预测结果的约束

DeWM 的思路是随机桥上的速度监督与积分后终点监督互补。它提醒我们：局部速度/训练点预测正确，并不保证完整推理结果正确。但论文中的线性 latent 桥是监督构造，不能解释为真实物理微轨迹，尤其在接触与突变附近。

当前 DeWM 代码将中间积分状态也拉向最终目标，与论文最终终点监督不同。借鉴时应该约束积分完成后的结果；如果要监督中间位置，应明确采用与时间一致的桥目标，而不是要求每一步都到终点。

### 6.2 不要增加一个代数上重复的 B loss

如果只定义 `Δ_hat=B(z0,a)-z0`，再监督 `Δ_hat≈z_future-z0`，误差正好等于 `B(z0,a)-z_future`。这与现有 latent MSE 相同，并没有增加 DeWM 意义上的过程监督。

真正的过程监督需要让模型接收桥中间状态和时间并预测速度，是一个新增训练问题。可以探索训练专用辅助分支、推理时仍使用直接 B，但这需要额外模型调用和损失平衡。应先只使用有真实未来的 recorded actions，再判断如何与 generated-action coupling 共存。

### 6.3 A 的积分终点监督也不能直接照搬

CoWM A 已有 `x_τ+(1-τ)v_θ` 的 clean-action estimate，它不是完整多步积分。若增加完整积分终点与示范动作的误差，会增加训练计算，还可能把同一目标条件下的多种合理动作压向单个示范。是否保留候选多样性、P3 的候选覆盖是否下降，都需要检查。

因此，先保证当前 A 的 few-step 生成、B 排名和 PO 行为被正确评价，终点辅助训练放在后面。

### 6.4 不推荐首先替换 B 为递归 flow

DeWM 在 H 个 action block 上递归，每个 block 积分 K 次；H=5、K=2 至少需要10次速度场查询。CoWM B 一次调用并行得到整个 prefix trajectory。批量候选仍可并行，但 horizon 和积分步上的依赖不会因此消失。

实际时间取决于网络大小、历史长度、attention backend等，不能从调用次数直接推断倍率。然而，对 CoWM 的少量决策时间目标，这个额外串行链已经构成明确的设计代价。除非先证明当前 B 的误差需要这种动力学结构解决，否则不应把它作为首个迁移方案。

## 7. 如何得到可解释的证据

### 7.1 固定物理候选池

先固定观测/目标、候选物理动作、动作合法性处理和执行预算。各评分器使用自己的 encoder/normalizer，评价同一组物理候选。

如果重新训练新表示的 A+B，A 的候选分布也会变。为了单独检查 B，可用一个冻结的参考 A 生成池子，再交给不同 B。不能将参考 A 的 latent 传给新 B，也不能在各自生成的新池子中比较排名后就认为隔离了表示因素。

候选池的真实结果需要 simulator replay 或已有真实候选执行记录。普通离线窗口只有 recorded action 的未来，不能给偏离它的 generated action 直接复用同一未来标签作为真实排序依据。

### 7.2 建议指标

| 层面 | 指标 | 要避免的误读 |
|---|---|---|
| 候选覆盖 | 池中真实成功候选比例/最好结果 | A 覆盖改善不能归因于 B 排序 |
| 排序 | selected regret、真实成功候选选中率、排序相关性 | latent MSE 更低不等于排名更准 |
| 闭环选择 | 同 A+各 B、Random-64、P0/P3 的配对结果 | 不同闭环轨迹不能声称一直处于同一候选池 |
| Refinement | PO 前后真实执行效果、失败/越界比例、cost 改善 | 自身 cost 下降不是环境改善 |
| 表示信息 | 位置/角度等探针、局部扰动响应、时序预测误差 | 探针准确不等于 goal distance 一定适合规划 |
| 成本 | batch=1 完整决策 P50/P95、参数/FLOPs、峰值显存 | 只测 encoder 或用批量耗时除以 batch 会漏掉实际决策成本 |

局部扰动探针可以区分局部几何与背景敏感性，但扰动不能随意被称为接触事件的因果证据。若测试接触前后的真实动态，应使用物理状态/事件标签及匹配样本。

### 7.3 推荐的实施顺序

1. 完成当前模型的候选池、执行结果及评分/梯度诊断，确认有足够的排序或 refinement 改进空间。
2. CLS-only CoWM 的 Sub-JEPA 正则对照：这是最小的训练目标变化。
3. 保持 B loss/正则策略的 R0–R3 表示对照，先做排名，再做闭环。
4. 在选定表示上固定参数比较 η，检查 P3 和 PO2 的真实收益与时间。
5. 单独比较 B 分量训练权重和独立 SIGReg。
6. 只有前述证据表明直接预测结构不足时，再研究过程辅助分支或 latent flow B。

每一步冻结配置、样本及主要对比后再看正式结果。这里提出的是待检验方案，不给出未经运行的增益预测。当前官方 Sub-JEPA baseline 的接入提供一个外部参考模型，并不意味着 CoWM 的训练正则或表示已经改变。
