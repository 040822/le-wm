# CVPR 表 3a：固定候选池排序结果

报告日期：2026-10-05。依据[总报告](cvpr_table3_report.md)及已验收的 `v1/3a` 产物整理。本次重新运行严格汇总验证器，24 个任务–种子单元全部通过；重建的 Markdown 与已有汇总逐字一致。

CoWM-B 的四任务宏平均所选成功率为 **86.58% ± 1.66%**，LeWM 为 **85.42% ± 1.66%**，描述性差值为 CoWM-B 高 1.17 个百分点。分任务成功率主检验均未通过 Holm 显著性阈值。Reacher 在完整 64 候选有效状态上的物理 regret 支持 CoWM-B；TwoRoom 和 Cube 的完整池连续指标无法估计。

## 协议与统计口径

四任务沿用 Table 1 的六个评估种子 `42, 100, 2026, 3407, 1234, 4444`。每单元保留 50 次源状态出现，每状态冻结 64 条候选动作；同一个 CoWM actor 生成候选，CoWM-B 和 LeWM 分别评分。共 1,200 次源状态出现、76,800 行候选分支结果。候选池成功覆盖率指至少一条候选在 25 步内成功；均匀选择 SR 是同一池上的期望值；所选 SR 是各评分器 top-1 候选的真实执行成功率。

下列 `±` 是六个评估种子估计的样本标准差，不是置信区间，也不是世界模型训练种子间的变化。任务内先计算每种子结果，再对种子等权；宏平均先在每种子内对四任务等权。配对差统一为 **LeWM−CoWM-B**。

连续主指标严格要求同一状态的全部 64 条候选均有合法的实际第 25 步后果。提前成功终止不补造第 25 步状态。regret 为所选真实代价减池内最小真实代价（越低越好）；Spearman 为预测代价与真实代价的相关系数（越高越好）。共同有效子池分析会在剩余有效候选上重新选择，因此其结果不能代替完整池 top-1 的表现。

物理代价：TwoRoom 为位置 L2（环境坐标单位）；PushT 为 `max(位置 L2/20 像素, wrapped angle/(π/9))`，位置项覆盖智能体及物块 XY；Reacher 为关节位置 L2（弧度）；Cube 为物块位置 L2（米）。跨任务原始 regret 单位不同，不将其简单宏平均用于论证总体排序能力。

## 主检验

与 3b 的 CoWM-PO 对随机扰动比较共同构成四任务 × 三比较的 12 项计划主检验，其中 9 项可估计。以任务内源回合为簇重采样 10,000 次，跨评估种子重复出现的同一源回合一并抽样，保留配对并对可估计种子均值等权平均。95% 区间为未做多重比较校正的 bootstrap 区间；Holm p 在 9 项可估计检验上校正。
