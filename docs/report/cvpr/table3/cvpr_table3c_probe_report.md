# CVPR 表 3c：观测潜在表示的物理状态探针

报告日期：2026-10-05。本报告涵盖 Cube（八个属性）已通过验收的 `v1/probe` 输出，以及 TwoRoom、PushT 和 Reacher 三项辅助任务。这些实验衡量从冻结图像编码器中读出当前物理状态的能力，不衡量预测状态解码、状态转移准确性或规划成功率。

在两类读出器下，Cube 已验收结果的总体得分均显示 CoWM 更优，其中末端执行器位置、夹爪和关节速度的差异较大。其他任务的结果并不一致：CoWM 的 TwoRoom 误差较低，LeWM 的 PushT 总体误差较低，而 Reacher 的差异较小。结论适用于所保存的检查点和本探针实验协议。

## 实验协议与数据划分注意事项

两个编码器接收完全相同的采样 RGB 数据行，标签也从相同的 HDF5 数据行读取。输入为 224×224 RGB，由 uint8 转换为取值在 [0,1] 内的 NCHW 浮点数，并使用 ImageNet 均值/标准差归一化。动作、目标、本体感知信息、标签值和观测历史均不进入任何一个编码器。每个模型均在评估模式下使用自身冻结的编码器与投影器，并输出 192 维潜在表示。LeWM 使用各任务的 Table 1 `weights.pt`，CoWM 使用对应的 `r4_ab_seed3072_weights_epoch_10.pt`。冻结配置文件记录了检查点路径和 SHA-256 哈希值。

采样种子为 20261005。每个任务无放回抽取 1,000 条符合条件的轨迹，再从每条轨迹中无放回抽取至多 100 帧。划分以轨迹而非单帧为单位：800 条训练轨迹、100 条验证轨迹和 100 条测试轨迹。采样时排除 Table 1 六个评估队列所含轨迹的并集：Cube、TwoRoom 和 Reacher 各排除 294 条轨迹，PushT 排除 296 条轨迹。轨迹长度不一致使 TwoRoom 和 PushT 的帧数少于 100,000。

特征与目标的均值/标准差仅使用探针训练集拟合。岭回归（Ridge）包含截距项，根据验证集从 alpha {0, 0.01, 0.1, 1, 10, 100} 中选择使标准化坐标 MSE 最小的值。MLP 架构为 192→256→256→目标维数，使用 ReLU、Adam（学习率 0.001）、批大小 256、至多 100 个训练轮次，早停耐心值为 10（patience）。MLP 读出器种子为 0、1 和 2。这些种子用于相同冻结世界模型检查点及相同数据划分下的读出器训练，并非独立的世界模型训练运行。

已保存的源代码审计指出，所检查的公开上游文件未提供官方探针命令行接口（CLI）或模块。实验采用 [Table 3 计划](../../../plan/cvpr_table3_plan.md)中的统一重跑协议。原始论文未明确指定部分目标映射、归一化、读出器及聚合方式；本报告不声称精确复现其 Table 3 的数值。

## 指标与目标定义

主表报告**标准化坐标均方误差（MSE）/ 各坐标 Pearson 相关系数 r 的均值**。MSE 将各坐标的平方误差除以训练目标标准差的平方后取平均，是无量纲指标。Pearson r 在汇集的测试帧上逐个目标坐标计算，再对有效坐标取平均。MSE 越低、r 越高越好。表中的目标单位描述底层标签的单位，并非标准化 MSE 的单位。物理坐标下的 MSE 和平均绝对误差（MAE）、逐坐标得分、对照读出器及补充角度/旋转指标保存在各任务的 `metrics.json` 中。

总体得分对各属性赋予相同权重，不受属性维数影响：Cube 为八个属性，TwoRoom 为一个，PushT 为三个，Reacher 为两个。它们不是将全部目标坐标汇集后得到的得分。本报告未定义跨任务总体得分。帧级点估计对各帧赋予相同权重，因此长度不同的轨迹贡献的帧数也不同。

Cube 物块位置和末端执行器位置采用世界坐标系 XYZ。物块四元数是原始 MuJoCo 自由关节四元数，顺序为 w/x/y/z。偏航角遵循 OGBench 的 SO(3) 约定。夹爪为 `clip(qpos[gripper_opening_joint]/0.8, 0, 1)`，不包含接触和速度。Cube 关节位置/速度各有六个坐标。TwoRoom 位置有两个坐标；PushT 智能体/物块位置各有两个，物块偏航角有一个；Reacher qpos/qvel 各有两个。所有目标均描述当前物理状态，没有以目标状态替代。

下表的 `±` 表示**三个 MLP 读出器种子之间的样本标准差**，不是置信区间或标准误。每个模型/属性的线性拟合只有一个确定性的最终结果。保留四位小数可能将非零标准差显示为 0.0000，或将 r 显示为 1.0000；精确值保存在聚合 JSON 中。

## 发现与局限

- **Cube：**CoWM 的总体标准化 MSE 较低（线性读出器 0.4536 对比 0.5215；MLP 0.4333 对比 0.5661），总体 r 较高。关节位置、关节速度、末端执行器位置、夹爪和物块四元数的线性 MSE 区间有利于 CoWM。线性物块位置读出有利于 LeWM；MLP 物块位置读出的均值有利于 CoWM。因此优势同时取决于属性和读出器类别。
- **Cube 朝向：**物块偏航角和末端执行器偏航角的相关系数接近零，线性读出器差值区间覆盖零。尽管 CoWM 的四元数坐标得分更好，其相关系数仍然较低。旋转 MAE 接近 1.6 弧度，不支持准确恢复朝向的主张。更大的 MLP 容量或更低的总体 MSE 均不能证明所有物理变量都得到了良好表示。
- **TwoRoom：**两个编码器都支持几乎精确的位置读出，尤其是使用 MLP 时。线性读出器配对区间有利于 CoWM。MLP 标准化 MSE 均值约为 0.000118833（LeWM）和 0.000064358（CoWM）；读出器种子 0 的 MSE 区间覆盖零，种子 1 和 2 则有利于 CoWM。表中保留四位小数的显示方式压缩了这一差别。
- **PushT：**CoWM 的智能体位置读出更好，而 LeWM 的物块位置和物块偏航角平均误差较低，且两类读出器的总体 MSE 都较低。线性物块位置区间覆盖零，线性偏航角区间则有利于 LeWM。仅凭任务级均值不能证明每个属性或 MLP 种子都有可靠差异。
- **Reacher：**两个模型的关节位置读出相近，速度读出较弱（标准化 MSE 接近 1，r 接近零）。两个属性的线性读出器差值区间都覆盖零。位置读出在不同坐标间并不均衡：CoWM 的线性 r 约为 0.4246/0.9987，LeWM 约为 0.4251/0.9963。两个坐标的均值掩盖了这种不均衡。

训练均值和按行打乱标签的线性对照读出器与最终读出器一并保存。训练均值对照的总体 MSE 为：Cube 0.9707、TwoRoom 1.0066、PushT 0.9918、Reacher 1.0132；其常数预测的 Pearson r 无法定义（`null`）。接近基线的朝向/速度得分需要按属性分别解释。较小的训练方差也可能放大标准化误差：例如，Cube 关节位置第五个坐标的训练标准差约为 0.000462 弧度，因此可以忽略的物理误差仍可能显著影响标准化 MSE。解释聚合得分前，应查阅物理单位和逐坐标结果。

这些实验确立了在所选监督读出器和数据分布下的可解码性，并未证明因果层面的物理理解、潜在动力学的正确性或该离线分布之外的鲁棒性。
