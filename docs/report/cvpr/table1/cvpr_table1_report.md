### 推理方式与预算定义

所有配置使用同一任务的固定 CoWM 权重。调用动作生成器时，均使用两步 Euler 积分；P1 不调用动作生成器。常规配置的生成／评分／执行跨度均为 25 个环境步，目标偏移为 25 步，总执行预算为 50 步。

| 协议 | 推理过程 |
|---|---|
| P0 | 生成一条动作序列，直接执行 |
| P1 | 在 CoWM 动力学模型上运行 CEM |
| P2 | 用生成的动作序列初始化 CEM，再优化 |
| P3 | 生成 64 条候选动作序列，由 CoWM 评分并选择 |
| P0-GF / P0-PO | 对单候选进行生成中梯度引导／生成后梯度优化 |
| P2-GF / P2-PO | 先引导／优化生成的动作序列，再用其初始化 CEM |
| P3-GF / P3-PO | 对全部 64 个候选进行引导／优化，再评分选择 |
| P3-PO-refine | 先从 64 个候选中选择，再仅优化选中的动作序列 |

GF 表示生成过程中的梯度引导（`guided_flow`），PO 表示生成后的梯度优化（`post_opt`）；`PO-refine` 对应 `post_opt_refine`。预算后缀定义如下：

| 后缀 | GF 更新预算 | PO / PO-refine 更新预算 |
|---|---|---|
| L（轻量） | 两个 Euler 步各更新 1 次，共 2 次 | 更新 2 次 |
| H（较大） | 两个 Euler 步各更新 5 次，共 10 次 | 更新 5 次 |

梯度更新步长为 0.01，最大 RMS 偏移为 0.2。GF 每个 Euler 步使用局部参考，PO 使用完整生成动作作为参考，因此相同后缀不表示 GF 与 PO 的计算量相同。P1/P2 的 CEM 使用 300 个样本 × 30 次迭代、top-k=30、方差缩放为 1；P2 初始化缩放为 1。

主版本（`main`）使用 `action_bound_mode=none`，关闭规划内部的额外动作投影，保留环境原生动作处理。裁剪版本（`crop`）中，P0/P3 及其变体使用 `clip`，P1/P2 及其变体使用 `candidate_clip`，在候选评分前投影至由真实物理动作边界换算得到的归一化边界；P3-PO-refine 在优化选中动作后再次投影。GF/PO 保持在未投影代价上计算梯度、随后投影的语义。

### 结果解读与溯源

主表 CoWM-Selection 对应主版本 P3，CoWM-Refinement 的两行分别对应主版本 P0-PO-L 和 P0-GF-L。下列比较依据完整矩阵的描述性统计，误差范围仅反映评估随机种子变化；每任务使用一个固定训练 checkpoint，未覆盖训练随机种子变化。

常规主版本中，P3-PO-L 与 P3-PO-H 的四任务平均成功率并列最高，分别为 96.42 ± 0.66% 和 96.42 ± 0.97%；相对 P3 的均值均提高约 0.17 个百分点。裁剪版本中，最高的是 P3-PO-L（96.42 ± 0.66%）。这些是对已完成矩阵的事后描述，不改变预先冻结的主表方法命名，也不据此宣称统计显著优势。

裁剪的影响依赖推理方式和任务：P1 的 Reacher 均值从 79.00% 升至 90.00%，但 TwoRoom 从 97.33% 降至 92.33%；P2 的 Reacher 从 76.00% 升至 87.33%，而 Cube 从 97.67% 降至 92.33%。增加引导／优化预算也未呈现一致提升，例如主版本 P3-GF-H 的四任务平均低于 P3-GF-L。
